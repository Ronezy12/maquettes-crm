# Maquettes · liste des prospects · Entreprise AR

Trois maquettes cliquables de la nouvelle liste des prospects du CRM :

- `tableau.html` : le tableau complet (filtres, colonnes, actions dans les lignes)
- `file.html` : la file de traitement (une fiche à la fois, résultat en un clic)
- `planning.html` : le planning des relances (glisser-déposer par jour)

`index.html` est la page d'accueil. Aucune dépendance : `runtime.js` affiche les pages, il n'y a rien à installer.

Toutes les données sont fictives.
